# 🌾 Agri Research AI

An AI-powered agricultural research platform. Upload research papers, ask
questions, and get answers generated by **Llama 3.3 70B** (via Groq),
grounded in your own documents through a **RAG** (Retrieval-Augmented
Generation) pipeline backed by **ChromaDB**.

## Tech Stack

| Component        | Technology                                   |
|-------------------|-----------------------------------------------|
| Frontend/UI       | Streamlit                                     |
| LLM               | Llama 3.3 70B                                 |
| LLM API           | Groq                                          |
| Vector Database   | ChromaDB                                      |
| Embeddings        | sentence-transformers/all-MiniLM-L6-v2        |
| PDF Processing    | PyPDFLoader (pypdf)                           |
| Text Splitting    | RecursiveCharacterTextSplitter                |
| RAG Orchestration | LangChain                                     |
| Config            | python-dotenv                                 |

## Setup

1. **Clone / unzip the project**, then move into the folder:
   ```bash
   cd agri-research-ai
   ```

2. **Create a virtual environment** (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Add your Groq API key:**
   ```bash
   cp .env.example .env
   # then edit .env and set GROQ_API_KEY=your_real_key
   ```
   Get a free key at https://console.groq.com

5. **Run the app:**
   ```bash
   streamlit run Dashboard.py
   # or: streamlit run app.py
   ```

6. Open the browser tab Streamlit gives you, go to **Research Assistant**,
   upload a PDF, click **Process Research Papers**, then ask a question.

## How it works (RAG pipeline)

```
PDF → PyPDFLoader → RecursiveCharacterTextSplitter (1000/200)
    → sentence-transformers embeddings → ChromaDB (persisted locally)

User question → similarity search in ChromaDB → top-k relevant chunks
    → stuffed into a prompt → Llama 3.3 70B (Groq) → answer + sources
```

## Notes on architecture decisions

- **No separate `backend/` package.** An earlier version used a `backend/`
  package with its own `pdf_processor.py`, `rag.py`, etc. This caused
  `ModuleNotFoundError: No module named 'backend'` and a circular import
  (`pdf_processor.py` importing itself indirectly through the package).
  The fix was to flatten everything the Research Assistant needs into
  `utils/rag_utils.py`, imported directly — no package-level circularity.
- **Standard `pages/` directory for navigation**, not `st.navigation()` /
  `st.page_link()`-based custom routing, which previously caused
  `Unable to create Page` and `KeyError: 'url_pathname'` errors on some
  Streamlit versions.
- **ChromaDB is empty until you upload and process a PDF** — this is
  expected; the dashboard reflects the current index size live.
